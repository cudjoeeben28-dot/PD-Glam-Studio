# PD Glam Studio
**Beauty • Style • Confidence**
PD Glam Studio is a professional beauty studio website designed to showcase beauty services and provide customers with a simple way to request appointments online.

## About the Website
The website presents PD Glam Studio's services, gallery, business information and online booking form in a modern, responsive design.

## Services
The website currently showcases:
- Wigs Making
- Pedicure
- Nails
- Hair Braiding
- Frontal Installation
- Manicure
- Lash Extension
- Makeup

## Gallery
The gallery currently features:
- Wigs Making
- Frontal Installation
- Lash Extension
- Makeup
- Nails
Additional images will be added later on as the business grows.

## Online Booking
Customers can request an appointment by providing:
- Full name
- Email address
- Phone number
- Selected service
- Preferred date
- Preferred time
- Additional information
The booking form is connected to **Formspree** for receiving appointment submissions and email notifications.
